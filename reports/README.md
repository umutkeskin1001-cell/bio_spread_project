# Reports Layout

- `reports/latest/`: canonical output of the latest normal pipeline run; replaced atomically on each run.
- `reports/history/`: archived older run directories moved out of root to keep this folder clean.
- `reports/release_verify_smoke/`: artifacts generated by release verification smoke checks.

Operational rule:
- Use default CLI run output (no custom `--output-dir`) to always refresh `reports/latest`.
